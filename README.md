One funny, painfully honest line imagining the comment a developer left above fragile production code: the kind of line that is funny because it is true. `main.py` (Python 3, standard library only) writes that single line to `entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
